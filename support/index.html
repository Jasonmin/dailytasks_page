常见问题

买断后仍显示免费限额？ 设置 → 恢复购买，或确认 App Store 登录与购买时相同的 Apple ID。

工作日 / 双休日 在新建任务 → 重复 → 每周，或点「工作日」「双休日」快捷按钮。

语言 跟随系统英文或简体中文。

提醒 设置 → 开启通知提醒；在任务编辑里为单条任务设定时间。摘要会在设定时间汇总当日待办。

Email: stephenmtree@gmail.com

Still on the free limit after purchase? Open Settings → Restore Purchases and use the same Apple ID as the purchase.

Weekdays / weekends are available when creating a task under Repeat → Weekly, or use the quick preset buttons.

Language follows the device (English or Simplified Chinese).

Reminders: Settings → Enable reminders; edit a task to set its time. The daily summary lists pending items at your chosen time.
